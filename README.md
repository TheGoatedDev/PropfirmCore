# PropfirmCore

TypeScript monorepo. pnpm + turborepo.

Node 24, pnpm 11. Exact versions only.

```sh
pnpm install
pnpm dev
pnpm lint
pnpm test
pnpm typecheck
```

Install [Renovate](https://github.com/apps/renovate) on this repo so dependency PRs show up. Local workflow lint: `brew install actionlint`.
